แลกโปรแกรมกับ GX Works2

      
Ladder ในเว็บแปลงเป็น Instruction List (IL) ของ MELSEC ให้อัตโนมัติ ส่งออกเป็นไฟล์ CSV เพื่อนำเข้า GX Works2 หรือนำไฟล์ CSV ที่ส่งออกจาก GX Works2 มาเปิดเป็น Ladder ที่นี่ก็ได้

      

        
        
        
        
      

      
      

        
        
      

      
    
        
  1. ใน GX Works2 คลิกขวาที่หน้า Ladder → Read from CSV File แล้วเลือกไฟล์ที่บันทึกจากเว็บนี้
    2. 
        
  2. จาก GX Works2 ไปเว็บ: คลิกขวาที่ Ladder → Write to CSV File แล้วกด “นำเข้าไฟล์ CSV / IL” ที่นี่
    3. 
      

    

    

      
รันโปรแกรมจาก GX Works2 กับเครื่องจำลองนี้ (Bridge)

      
ให้โปรแกรม Ladder ที่รันอยู่ใน GX Simulator2 ขับเครื่องจำลองนี้แบบเรียลไทม์: เว็บส่งสถานะเซนเซอร์ X0–X7 ไปให้ และอ่าน Y0–Y7 กลับมาขยับเครื่อง ผ่านโปรแกรมตัวกลาง gx_bridge.py ที่รันบนเครื่องคอมพิวเตอร์ของคุณ

      

        
        
      

      
ยังไม่เชื่อมต่อ · เครื่องจำลองใช้โปรแกรมในเว็บ

      
    
        
  1. GX Works2: Debug → Start/Stop Simulation (เปิด GX Simulator2 ให้ RUN)
    2. 
        
  2. MX Component → Communication Setup Utility: สร้าง Logical Station No. 1 เลือกการเชื่อมต่อเป็น GX Simulator2
    3. 
        
  3. เปิด Command Prompt: pip install pywin32 websockets แล้ว python gx_bridge.py --station 1
    4. 
        
  4. เปิดไฟล์ plc-training-kit-sim.html จากเครื่อง (ไม่ใช่ลิงก์ออนไลน์) แล้วกด “เชื่อมต่อ”
    5. 
      

    

  


  

    

      
การต่อ I/O ของชุดฝึก

      

    

    

      
คำสั่ง Ladder ที่รองรับ (FX)

      
    
        
  • คอนแทค LD LDI LDP LDF · AND ANI ANDP ANDF · OR ORI ORP ORF
    • 
        
  • เปรียบเทียบ LD= LD<> LD> LD< LD>= LD<= (และ AND/OR)
    • 
        
  • เอาต์พุต OUT SET RST PLS PLF
    • 
        
  • ไทเมอร์ OUT T0 K20 (T0–T199 ฐาน 100 ms, T200–T245 ฐาน 10 ms)
    • 
        
  • เคาน์เตอร์ OUT C0 K5 · รีเซ็ต RST C0
    • 
        
  • ข้อมูล MOV(P) INC(P) DEC(P) กับ D0–D7999
    • 
        
  • รีเลย์พิเศษ M8000 RUN, M8002 พัลส์แรก, M8012 0.1 s, M8013 1 s
    • 
      

    

    

      
วิธีเขียน Ladder

      
    
        
  • คลิกช่อง แล้วกด F5 พิมพ์ X0 Enter (หรือดับเบิลคลิกแล้วพิมพ์ LD X0)
    • 
        
  • วงจรขนาน: ไปแถวล่าง กด Shift+F5 เส้นตั้งจะต่อให้เอง
    • 
        
  • F7 พิมพ์ Y3 วางคอยล์ท้ายแถว · F8 พิมพ์ SET M10
    • 
        
  • แก้โปรแกรมขณะ RUN ได้ (Online change) ค่าในหน่วยความจำไม่หาย
    • 
        
  • ขณะ RUN คอนแทค/คอยล์ที่ทำงานจะเป็นสีน้ำเงินแบบ Monitor ของ GX Works2
