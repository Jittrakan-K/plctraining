Real-time control

        
The page sends sensors and buttons X0 to X7 to the program in GX Simulator2 and reads Y0 to Y7 back to move the machine, through gx_bridge.py on your computer.

First-time setup

          
    
            
  1. GX Works2: choose Debug, then Start/Stop Simulation so GX Simulator2 is in RUN.
    2. 
            
  2. MX Component (Communication Setup Utility): create Logical Station No. 1 of type GX Simulator2
    3. 
            
  3. Install with pip install pywin32 websockets then run python gx_bridge.py --station 1
    4. 
            
  4. Open plc-training-kit-sim.html from your computer (the online page cannot reach localhost) and press “Connect”.

User guide

      
From choosing an exercise to sending the program to a real PLC.

    

    

      

        01
Choose an exercise and run it

        

          
Choose an exercise from the list in the Program panel and press Run or Ctrl+Enter. The goal appears below the list, for example sort 5 parts with no errors, and is marked when you pass. The sorting result sits beside the Workspace heading.

        

      

      

        02
Writing Ladder as in GX Works2

        

          
Click a cell in the Ladder grid and press F5 for an NO contact, F6 for an NC contact, Shift+F5 for a parallel branch, F7 for a coil and F8 for an instruction, then type the device and press Enter. Elements that do not reach a coil get a dashed red frame.

        

      

      

        03
Testing on the machine

        

          
Press START and STOP on the machine picture or in the I/O tab. Add metal or plastic parts yourself or turn on auto feed. If your program has no pick and place, tick “Skip gripper”. The real kit has no cylinder position sensors, so the example programs use timers.

          
The Monitor tab shows the M, T, C and D devices in your program while it runs.

        

      

      

        04
Sending the program to GX Works2

        

          
Press “Save CSV” in the GX Works2 section, then in GX Works2 right-click the Ladder window and choose Read from CSV File. To bring a program back, choose Write to CSV File then press “Import CSV or IL” here.

        

      

      

        05
Instruction set and languages

        

          

            
Ladder instructions (FX)

            
    
              
  • Contacts LD LDI LDP LDF AND ANI ANDP ANDF OR ORI ORP ORF
    • 
              
  • Compare LD= LD<> LD> LD< LD>= LD<= with AND and OR forms
    • 
              
  • Output OUT SET RST PLS PLF
    • 
              
  • Timers OUT T0 K20 (T0 to T199 at 100 ms, T200 to T245 at 10 ms)
    • 
              
  • Counters OUT C0 K5, reset with RST C0
    • 
              
  • Data MOV(P) INC(P) DEC(P) on D0 to D7999
    • 
              
  • Special relays M8000 RUN, M8002 first scan, M8012 0.1 s, M8013 1 s
    • 
            

          

          

            
Languages

            
    
              
  • LD Ladder as in GX Works2
    • 
              
  • IL MELSEC IL, Siemens STL (A I0.0 = Q0.3), Allen-Bradley (XIC(I:0/0) OTE(O:0/3))
    • 
              
  • ST CODESYS style, I/O as X0 or %IX0.0
    • 
              
  • SFC N, S and R actions, step time with Check.T >= T#2S
    • 
              
  • FBD AND, OR, TON and CTU blocks wired by dragging
    • 
              
  • The 3D view needs an internet connection the first time
